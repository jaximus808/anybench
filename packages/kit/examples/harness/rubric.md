# Rubric

## Code quality

Score 1 to 4. Quote file paths and lines from the frozen workspace as evidence.

- 4: small, readable modules; tests cover the edge cases in the instruction; no dead code.
- 3: readable with minor duplication; tests cover the main paths.
- 2: works but hard to follow, or tests are thin.
- 1: tangled, untested, or works by accident.
